## Implementación y evaluación de filtros digitales

 **Nombre:** Miguel de Jesus Salazar Garcia
**Matrícula:** 96339

En esta actividad se crearon filtros digitales utilizando Python.
 
Se generó una señal con frecuencias de 50 Hz, 200 Hz y 400 Hz. También se agregó ruido blanco para observar los cambios antes y después del filtrado.

 Los filtros utilizados fueron:

- Filtro pasa bajos.
- Filtro pasa altos.
- Filtro pasa bandas.
- Filtros FIR con ventana de Hamming.
- Filtros IIR Butterworth.


Las librerías utilizadas fueron:
  - NumPy.
- SciPy.
- Matplotlib.
